# P0 验收清单

## 自动验收

在已安装 Flutter、Node.js 和 Docker Compose 的管理机执行：

```powershell
./deploy/p0-acceptance.ps1
```

## 核心业务场景

- [ ] 手机验证码登录，重新启动 App 后仍保持登录；
- [ ] 创建家庭，邀请另一账号加入，并切换多个家庭；
- [ ] 添加儿童/长辈档案，编辑身份，设置监护关系；
- [ ] 管理员交接后旧管理员降为成人，新管理员可管理成员；
- [ ] 新建、编辑和删除日程，勾选完成任务；
- [ ] 离线新增日程、任务、账目和记录，恢复网络后只生成一份数据；
- [ ] 新增家庭账目，分类汇总与明细金额一致；
- [ ] 发布含照片记录，并验证全家、仅自己、管理员、指定成员四种可见范围；
- [ ] 新增成长里程碑，并按成员查看；
- [ ] 非授权成员无法访问健康档案；授权后按只读/可编辑权限访问；
- [ ] 新增就诊和用药计划，手机按时提醒，可记录已服或跳过；
- [ ] NAS 重启后 API、Worker、PostgreSQL、Redis 和 HTTPS 自动恢复。

## 备份与恢复演练

创建备份：

```sh
docker compose --profile maintenance run --rm backup
```

使用新建的空白测试环境恢复，禁止直接覆盖唯一生产实例：

```sh
docker compose --profile maintenance run --rm restore /backups/<时间戳>
```

恢复后核对家庭、成员、日程、账目总额、记录附件、健康授权和用药计划，并随机打开至少三张照片。

## 发布通过标准

- 自动验收全部通过；
- 上述人工场景全部勾选；
- Android 真机安装包运行无阻塞性问题；
- 备份恢复至少成功演练一次；
- 未发现跨家庭、跨成员的隐私越权。
