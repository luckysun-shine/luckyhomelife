## 安全边界

- 所有家庭业务接口先校验家庭成员身份；
- 个人账本仅所属成员可访问；
- 健康档案仅本人、管理员或明确授权成员可访问；
- 家庭记录查询和照片下载使用相同的可见范围判断；
- 邀请码和登录验证码只保存摘要；
- 正式环境强制关闭开发登录；
- 写入接口使用客户端操作标识或版本号防止重复与静默覆盖。
