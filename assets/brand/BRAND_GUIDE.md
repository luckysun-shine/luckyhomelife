# HomeLife OS 品牌使用规范

## 品牌概念

开放的双弧线代表家人的环抱与连接，日出代表每一天的新生活，两条交汇路径代表不同世代共同生活和成长。图形刻意避免传统屋顶，使品牌更开放、更有活力。

## 标准颜色

| 名称 | HEX | 用途 |
| --- | --- | --- |
| 活力珊瑚橙 | `#FF6548` | 主行动色、右侧弧线和成长路径 |
| 清新青绿色 | `#18BFAE` | 家庭连接、左侧弧线和生活路径 |
| 阳光黄色 | `#FFC83D` | 日出和少量强调 |
| 温暖象牙白 | `#FFF8ED` | App 图标和浅色背景 |
| 活力深海蓝 | `#17324D` | 字标、正文和深色背景 |

深色背景使用提亮后的青绿 `#28D7C3`、珊瑚 `#FF765B` 和黄色 `#FFD15C`。

## 文件选择

- `homelife-symbol-color.svg`：默认彩色图形标；
- `homelife-logo-horizontal.svg`：浅色背景横版主标；
- `homelife-logo-horizontal-dark.svg`：深色背景横版主标；
- `homelife-symbol-mono.svg`：单色印刷、文档页脚；
- `homelife-symbol-white.svg`：照片或品牌色背景反白；
- `homelife-app-icon.svg`：默认 App 图标；
- `homelife-app-icon-coral.svg`：珊瑚色活动版图标。

## 留白与最小尺寸

- 标志四周至少保留太阳直径一半的留白；
- 图形标数字界面最小宽度 24px；
- 横版标志最小宽度 140px；
- 小于 140px 时只使用图形标，不显示字标。

## 禁止事项

- 不改变各图形的相对比例；
- 不为核心标志添加渐变、投影、描边或立体效果；
- 不替换标准色或降低到难以辨认的透明度；
- 不把图形拉伸、倾斜或放入复杂背景；
- 不单独移动太阳或交换两条路径的颜色。
